# 人工客服升级与禁止承诺

## 需要转人工的情况

- 工具没有数据、数据冲突或顾客无法通过必要核验；
- 需要真实执行退款、取消订单、补发、修改地址或价格补偿；
- 质量争议、责任认定或赔付方案无法依据现有信息判断；
- 多次物流异常、疑似丢件或签收争议；
- 账户、支付、隐私或诈骗风险；
- 达到演示规则的大单或批量退货人工复核阈值；
- 顾客明确要求人工客服。

转人工时只传必要信息，清楚说明下一步和真实平台渠道；转接不等于拒绝售后，也不能因此忽略依法适用的时限。

## 禁止承诺清单

- “明天一定送到”“保证按时送达”；
- “退款今天一定到账”；
- “已经帮你退款/取消/改地址”，但系统没有成功写入凭证；
- “这个商品绝对不会坏/一定适合你”；
- 未经核实的赔偿金额、赠品、优惠券或责任认定；
- 未核实实际店铺规则时称“大单不支持退货”“已经退款”“七天无理由要先经人工批准”；
- 以国家法律名义描述店铺私有规则。

推荐表达：说明当前已知事实、条件和下一步；不确定时使用“预计”“以系统更新为准”“需要人工进一步核实”。
