# 七日无理由退货与质量问题售后

## 七日无理由退货

网络购买商品通常可自收到商品之日起七日内无理由退货，但存在法定例外，包括消费者定作商品、鲜活易腐商品、在线下载或消费者拆封的音像制品和计算机软件等数字化商品、交付的报纸期刊等。其他根据商品性质不宜退货且购买时经消费者确认的商品，也可能不适用。

退回商品应当完好。合理查验而打开包装，一般不能被简单等同于商品不完好；超出查验需要、影响商品完好的使用可能影响无理由退货。

无理由退货产生的运费原则上由消费者承担；经营者与消费者另有约定的，从其约定。

具体商品的公开售后标签须逐商品核实；公开快照未显示标签，不代表客服能自行承诺或否定法定权利。真实店铺额外承诺应以原商品页、订单页等可核验规则为准。

## 质量问题

商品不符合质量要求时，顾客可以依照国家规定、双方约定要求退货，或者要求更换、修理。超过七日无理由期限，不等于质量问题售后权利当然消失。

经营者履行退货、更换、修理等义务时，应承担运输等必要费用；不能把无理由退货由顾客承担运费的规则直接套用到质量问题。

客服应先核对订单、问题描述和必要凭证，再根据商品类别、法定责任和店铺承诺判断。不能确认时转人工，不应直接拒绝。

批量或大额订单退货按演示规则转人工复核，但不能因金额或件数大而直接拒绝，也不能借人工复核延后或缩减法定权利；具体示例阈值参见《大单退货人工复核》。

法律依据包括《中华人民共和国消费者权益保护法》《中华人民共和国消费者权益保护法实施条例》和《网络购买商品七日无理由退货暂行办法（2020 年修订）》。具体处理以现行法律法规及订单页面公示承诺为准。
