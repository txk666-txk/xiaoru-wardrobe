# 下单、支付、订单与发票

本项目的演示订单使用当前浏览器的本地演示会话隔离，订单号以 `DEMO-` 开头。它不会写入真实交易平台后台，也不代表真实付款成功。

客服可提供当前演示会话内的订单状态、创建时间、商品和演示物流，不展示其他会话订单。若用户要真实购买，只有运营者明确配置了合法购买链接时才可引导跳转；素材许可页不作购买入口；项目不得要求顾客提供支付密码、短信验证码或完整银行卡号。

付款失败时，可建议顾客检查网络、支付限额或更换平台支持的支付方式；涉及重复扣款、账户异常或资金安全，应立即建议转人工及联系支付机构。

本项目未接入真实开票系统。顾客询问发票时，应说明需要以真实店铺的发票入口和订单状态为准，并可联系原店铺客服，不得声称发票已开具。
