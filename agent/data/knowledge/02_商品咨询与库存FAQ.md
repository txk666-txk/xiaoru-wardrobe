# 商品咨询与库存 FAQ

## 商品事实从哪里来

商品名称、型号、参考价、规格、尺码与库存必须调用 ProductTool 查询当前商品 Provider，不能从知识库中的例子或旧对话推断。知识库只说明客服口径，不保存会变化的商品清单与库存数字。

本机可导入已有快照中的历史服装照片与已记录属性，存在该目录时优先使用；干净克隆使用随仓库分发的8张 Wikimedia Commons 开放许可真实服装照片。公开小样的价格、库存和尺码是演示参数；本机快照中的数据是历史参考，不代表实时在售。商品图是真实服装照片，不能因此把沙盒参数当作真实商家承诺。

## 常见回答原则

- 询问价格：先调用工具，按返回的数据来源说明是演示价或历史参考价；没有实时后台时不能声称实时优惠或正式成交价。
- 询问库存：先确认商品编号及颜色、尺码，再查询。工具只有总库存时只能报告总量，不能拆分成各颜色、尺码库存；未知库存明确说未收录，不当成有货或售罄。
- 询问尺码：只使用该单品已记录的尺码资料，不借用其他商品的尺码表，不仅凭身高体重保证合身。没有资料时说明需要补充成衣尺寸。
- 询问推荐：根据已给预算、用途、风格、颜色和版型筛选工具可查的商品，简述匹配点。必要时只追问一两个关键偏好，不贬低竞品、不制造稀缺。
- 检索不到：说明当前目录未找到，可询问品类、预算或偏好后再调用商品工具寻找替代，不虚构型号或候选。

## 禁止事项

不虚构参数、功效、认证、材质、保修、价格或库存。不用“最后一件”“马上涨价”等未经工具证实的说法催促。目录和模型都不执行真实支付、下单或发货。
