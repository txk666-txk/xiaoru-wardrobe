# 商品目录与数据声明

## 项目定位

「小如的衣橱」是服装电商场景的数字客服 Agent 与试衣演示，不冒充任何真实商家。当前有哪些商品、类别、型号、参考价、尺码与库存，以本轮商品工具查询的 Provider 为准，不能从本文件给出固定全店清单。

## 两类服装数据

- 本机可以从已有历史快照导入服装照片与已记录属性，优先供本机商城、搭配和试衣使用。导入不连接真实商家后台；没有记录的面料、尺码和库存保持未知，不补造。
- 干净克隆回退到8张 Wikimedia Commons 的真实服装照片，逐图记录 CC0 或 CC BY 许可；对应价格、库存与尺码只是沙盒参数。
- 本机导入图与公开小样均为实际服装照片。图片可用于已配置 FASHN 服务的试衣；具体单品是否支持、图片类型和服装类别仍需读取工具结果。
- 本机第三方参考图保留原来源与权利状态，不随公开仓库分发；更换展示名不改变图片权利，不代表商家授权或品牌合作。

## 交易与资料边界

购物车、账户余额、订单、物流与售后均在本地沙盒执行，不发生真实支付、发货或退款。本机参考价、库存与规格可能过期，公开小样参数也不能用于真实购买决策。素材来源链接用于说明出处与许可，不自动等于购买入口。

## 信息优先级

1. 当前商品工具返回的结构化数据、来源和未知字段。
2. 该单品明确记录的属性与尺码资料。
3. 本知识库的通用服务口径。
4. 无法核验则明确未知，必要时请运营者补录或转人工。

不根据标题或图片推断未记录的面料比例、弹力、保暖等级、洗护、发货时效、包邮、售后承诺或具体尺码库存。试衣图是生成效果，不保证真实合身或完整还原实物细节。
