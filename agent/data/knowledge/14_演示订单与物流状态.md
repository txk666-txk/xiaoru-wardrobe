# 演示订单与物流状态

## 订单状态

- `pending_demo_confirmation`：等待顾客确认演示订单。
- `demo_created`：本地演示订单已创建，未支付、未提交外部平台。
- `awaiting_demo_fulfillment`：等待演示发货。
- `shipped`：已生成演示物流单。
- `in_transit`：演示运输中。
- `delivered`：演示签收。
- `closed`：演示订单已关闭。

## 物流时间线

物流界面按时间顺序展示节点、地点和说明。所有节点均需带“演示物流”标签，不能与真实承运商轨迹混淆。预计时间只能作为估计，不能表述为一定送达。

## 查询要求

- 真实交易平台订单无法在本项目中查询，因为没有连接店铺后台。
- 本地演示订单仅按当前浏览器的演示会话隔离，不能通过用户随意提交的用户名读取他人订单。
- 找不到订单时，说明可能不是当前演示会话创建的订单，不要猜测状态。
