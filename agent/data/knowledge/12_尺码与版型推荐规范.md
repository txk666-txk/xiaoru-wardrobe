# 尺码与版型推荐规范

## 核心原则

尺码助手是低风险建议，不是合身保证。只有单品存在已核验的专属尺码表或公开尺码区间时，才可以给出具体尺码候选；不同商品不能套用同一张全店尺码表。

## 信息最小化

- 基础初筛：身高、体重、偏好宽松或合身。
- 上装与外套进一步参考胸围、肩宽。
- 裤装进一步参考腰围、臀围和常穿裤码。
- 身体数据只用于本次计算，不写入长期记忆、知识库、日志或向量库。

## 推荐规则

1. 将斤换算为千克时使用 `1 斤 = 0.5 千克`。
2. 若商品只提供体重区间，按该单品区间给出候选，并提示重叠区间需要结合版型偏好选择。
3. 位于两个尺码重叠区间：偏合身倾向较小码，偏宽松或需要叠穿倾向较大码。
4. 接近区间边界、体型差异较大、修身款、裤装或顾客提供的胸腰臀围与体重建议冲突时，应降低置信度并建议核对成衣尺寸。
5. 无专属尺码表时不得猜码，应提示查看原商品详情或让店主补录尺码表。

## 示例边界

有的宽松上装可能公开 `S <110斤、M 110–140斤、L 130–160斤`，但修身吊带可能使用完全不同的 `S 80–90斤、M 90–100斤、L 100–120斤`。这说明尺码推荐必须绑定具体商品。

## 禁止承诺

不得使用“保证合身”“一定不会小”“按体重买肯定没问题”等表述。推荐结尾应说明：“这是基于公开尺码提示的参考建议，身形和穿着偏好会影响效果，请再核对商品页成衣尺寸。”
