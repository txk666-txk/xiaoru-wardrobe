# 演示购买与订货流程

## 适用范围

本项目的购买和订货用于展示数字客服 Agent 如何完成商品选择、规格确认、购物车和订单编排，不会创建真实交易平台订单，也不会发起支付。

## 标准流程

1. 顾客选择商品。
2. 若当前商品工具有已记录选项，选择颜色和尺码；若没有，标记为“待人工确认规格”。
3. 加入本地演示购物车。
4. 服务端根据当前 Provider 重新计算参考金额，不信任浏览器传来的金额。
5. 展示演示订单预览：商品、规格、数量、参考单价、参考合计和数据声明。
6. 顾客明确点击或回复确认后，生成 `DEMO-` 前缀订单。
7. 页面提示“演示订单已创建，仅使用沙盒余额，未发生真实支付、未提交至商家后台”。

## 真实购买入口

若运营者另行配置了合法购买链接，可引导顾客打开该页面核实实时价格、库存、配送与支付规则。Commons 素材页与本机来源映射不作为购买入口，未配置时应说明当前只能体验沙盒。客服不得要求顾客把支付密码、短信验证码或完整银行卡信息发到聊天中。
