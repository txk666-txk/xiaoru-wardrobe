# 退换货申请流程

## 本地演示售后

1. 选择当前演示会话中的 `DEMO-` 订单。
2. 选择商品、申请类型和原因，可补充问题描述。
3. 先生成售后预览，展示订单状态、商品、原因和适用边界。
4. 顾客再次确认后生成演示售后申请。
5. 售后状态按 `draft → submitted → reviewing → approved/rejected → return_in_transit → received → demo_refund_completed` 演示流转。

## 公开商品售后标签

售后能力必须逐商品读取公开详情：有的商品同时显示七日无理由和支持退换，有的只显示七日无理由，也可能没有公开显示相关标签。未显示不等于可以自行承诺支持；应引导顾客查看原商品页并与真实店铺客服确认。

## 质量问题

质量问题不应仅因超过七日无理由期限而直接拒绝。应核对订单、问题描述和必要凭证，再根据真实交易平台和法律规则处理。本项目无权替真实店铺审批或完成退款。

## 大单退货人工复核

演示分流规则将同一订单达到 10 件，或实付总额达到 5000 元的退货请求转人工核对订单明细与适用政策。阈值是演示配置，不是 任何真实店铺已经公示的规则，也不是拒绝或减少法定售后权利的门槛。真实订单须通过原交易平台或商家客服处理；自动客服只记录必要诉求，不得声称已批准或完成退款。详见《大单退货人工复核》。

## 隐私与凭证

仅收集处理当前问题所需的最少信息。不要索取支付密码、短信验证码、完整银行卡号或无关身份证信息。图片凭证若尚未实现安全上传，只记录文字说明并建议转人工。
