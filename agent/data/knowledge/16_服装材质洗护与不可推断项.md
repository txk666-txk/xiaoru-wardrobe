# 服装材质、洗护与不可推断项

## 回答依据

面料成分、里料、填充物、克重、弹力、透气、防水、防晒、保暖和洗护方式必须来自具体商品公开属性或商品详情。商品名称中出现“羊毛”“羽绒”“防水”“防晒”等词，不足以单独证明成分比例或性能等级。

## 通用安全口径

- 首次洗涤前查看商品洗标和原商品页说明。
- 深浅色通常建议分开处理，但若商品有专属洗护要求，以专属要求为准。
- 印花、涂层、特殊做旧、毛呢、羽绒和含弹力纤维商品可能需要不同护理方式，未核验前不要给出强制性的水温、机洗或烘干结论。
- 不知道材质比例时，直接说明当前商品工具资料未收录，不要凭图片猜测。

## 禁止医学或性能承诺

不得宣称服装具有未经认证的抗菌、治疗、绝对防过敏、绝对防水、永久防晒或其他功效。对敏感肌或过敏顾客，应建议核对完整成分并结合自身情况判断。
