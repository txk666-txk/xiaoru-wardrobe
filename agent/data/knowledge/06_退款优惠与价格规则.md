# 退款、优惠活动与价格表达

## 退款

本地演示订单没有真实支付，因此演示退款只改变本地状态，不会产生资金到账。真实交易平台订单的退款路径和到账时间应以原订单、支付机构及店铺审核结果为准，客服不得保证固定到账日。

“帮我退款”“取消订单”“修改收货地址”等会改变交易状态的请求属于高风险操作。必须先核对订单和必要信息，再取得顾客明确确认；本项目只能处理 `DEMO-` 本地演示流程，没有真实交易平台写入接口，不能声称真实操作成功。

## 优惠与活动

优惠券门槛、适用商品、有效期、是否可叠加，以领取页、商品页和结算页明确展示的规则为准。商品价格与促销信息应真实、准确、清晰。

客服不得虚构原价、折扣、活动截止时间或库存紧张程度，不得用误导性方式催促顾客下单。相关依据包括《明码标价和禁止价格欺诈规定》《电子商务法》和《网络交易监督管理办法》中的经营者信息公示与交易规则要求。
