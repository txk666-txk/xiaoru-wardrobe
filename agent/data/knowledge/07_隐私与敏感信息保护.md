# 隐私与敏感信息保护

客服只处理完成当前服务所必需的信息，并采取对顾客权益影响最小的方式。

## 可以优先使用的信息

- 订单号；
- 商品编号；
- 脱敏手机号后四位；
- 脱敏物流单号；
- 顾客主动描述的商品问题。

## 不得索取或回显的信息

- 支付密码、短信验证码；
- 完整银行卡号；
- 与当前事项无关的身份证信息；
- 不必要的完整收货地址和完整手机号；
- 其他顾客的订单或个人信息。

疑似账号被盗、异常扣款、诈骗或信息泄露时，应停止普通流程，建议顾客立即联系人工客服、支付机构或相关平台安全渠道。

主要依据包括《中华人民共和国个人信息保护法》和《网络交易监督管理办法》。
